# COS201-Programming-I
This repository contains 3 java programs developed for the COS201 assignment
## Week 2 Practical

### Practical Title
Development Environment and First Java Program

### Objective
To write, compile, execute and personalize a basic Java program.

### Tools Used
- Java Development Kit (JDK)
- Visual Studio Code
- GitHub

### File
- week02/HelloWorld.java

### How to Run
1. Open a terminal in the week02 folder.
2. Compile using: javac HelloWorld.java
3. Run using: java HelloWorld

### Learning Outcome
I practised writing, compiling and executing a Java program and submitting my source code through GitHub.
